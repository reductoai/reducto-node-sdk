# Security Policy

## Reporting Security Issues

Reducto takes security seriously, and encourages you to report any security vulnerability promptly so
that appropriate action can be taken.

To report a security issue in this SDK, please contact dev-feedback@reductoai.com. Please do not open a
public GitHub issue for security vulnerabilities.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us maintain the security of
this SDK. If you believe you have found a security vulnerability, please adhere to responsible
disclosure practices by allowing us a reasonable amount of time to investigate and address the issue
before making any information public.

## Reporting Non-SDK Related Security Issues

If you encounter security issues that are not directly related to this SDK but pertain to the services
or products provided by Reducto, please contact dev-feedback@reductoai.com.

---

Thank you for helping us keep this SDK and the systems it interacts with secure.
